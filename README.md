This does not come with a repo. You will need to make a local repo yourself. There are two ways you can go about doing this. You can either figure out how to do that on the gentoo wiki, or you can make a local copy of my personal overlay. If you do not copy my overlay, you will need to (easily) edit the ebuild so that the file directories match the name of the overlay (just find and replace "yourlocaloverlay" with whatever your repo is called). It is designed this way because I am stupid and just wanted it to work. In the this repo, you will find 2 things: the ebuild file directly, as well as a zipped version of my overlay. You can either use the ebuild as you please, or you can unzip the overlay and place it such that it is structured like this: `/var/db/repos/yourlocaloverlay/net-im/`. After this, you should be able to run `sudo eselect repository enable yourlocaloverlay`. then simply run `emerge net-im/fluxer` with your preferred flags. 

This package does not compile anything, it simply fetches the latest tar.gz file from fluxer.app and then puts the files in '/opt/fluxer'.

I am not familiar enough with writing ebuilds to know how to include a desktop file, so you will need to manually install it to `~/.local/share/applications`.
